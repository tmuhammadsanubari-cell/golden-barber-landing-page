# M2 — Database & Data Asli

**Estimasi:** 4–6 hari · **Fitur PRD:** F-08, F-13 · **Rujukan:** PRD 4.2 (skema & RLS), 4.7 (deploy)

Tujuan: data pindah ke Supabase. Build mengambil data dari Supabase. Halaman `/cabang/[slug]` dan SEO lokal jadi.

**Butuh dari user:** project Supabase (URL, anon key, service role key). Minta di awal milestone, isi ke `.env` (bukan ke repo).

## 1. Supabase

- [ ] `npx supabase init` (pakai folder `supabase/` yang ada), `npx supabase link --project-ref <ref>`.
- [ ] Migrasi `supabase/migrations/`:
  - [ ] `..._init_schema.sql` — enum + 11 tabel PRD 4.2, constraint, index, partial unique `is_flagship`.
  - [ ] `..._triggers.sql` — `set_updated_at` semua tabel; auto-insert `branch_services` saat cabang/layanan baru.
  - [ ] `..._rls_policies.sql` — `is_admin()`, `is_super_admin()`, policy sesuai tabel RLS PRD.
  - [ ] `..._storage.sql` — bucket `media` (baca publik, tulis admin).
- [ ] `supabase/seed.sql` dibuat **dari** `src/data/seed/*.json` (tulis script kecil `scripts/build-seed-sql.ts` agar bisa diulang). Relasi pakai slug → id.
- [ ] `npx supabase db push`, jalankan seed, `npx supabase db lint` bersih.
- [ ] Generate `src/types/database.ts`.

## 2. Ganti sumber data

- [ ] `src/lib/supabase/build.ts` (anon key, dipakai saat build) dan `server.ts`/`service.ts` (dipakai M3).
- [ ] Isi `src/lib/data/*` diganti query Supabase. Antarmuka fungsi tidak berubah.
- [ ] Simpan fallback: env `DATA_SOURCE=json|supabase` (default `supabase`) supaya dev tanpa internet tetap jalan.

## 3. Halaman cabang & SEO

- [ ] `src/pages/cabang/[slug].astro` + `getStaticPaths` dari cabang aktif. Ikut mockup `Cabang-Dago*.dc.html`.
- [ ] `src/pages/404.astro` ikut mockup `404*.dc.html`.
- [ ] `src/lib/seo.ts`: JSON-LD `HairSalon` per cabang, `Organization` di beranda, `FAQPage`.
- [ ] Title/description unik, Open Graph, canonical, `@astrojs/sitemap`, `public/robots.txt` (blok `/admin`, `/api`).
- [ ] `src/pages/kebijakan-privasi.astro` (teks singkat: data lead dipakai untuk menghubungi, IP disimpan sebagai hash).

## Definition of Done

- [ ] Data di situs identik dengan `src/data/seed/` (cek acak 3 cabang).
- [ ] Uji RLS: request anon `insert`/`update` ke tabel konten ditolak; `select` hanya baris aktif.
- [ ] 11 halaman `/cabang/*` ter-build; Rich Results Test tanpa error untuk `/cabang/dipatiukur`.
- [ ] Build lolos. Update `docs/PROGRESS.md`.
